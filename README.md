# D&D AI DM — V1

Prototype interface untuk campaign tabletop-style dengan AI Dungeon Master.

## V1 saat ini
- Freeform player action, tanpa pilihan A/B/C.
- Scene panel.
- Character stats Ilgar Zamani.
- HP / AC / level / gold.
- Inventory dasar.
- Local d20 roller.
- Chat log lokal.

## Roadmap
1. Test UI di HP.
2. Pisahkan data character dan campaign state.
3. Sambungkan Supabase.
4. Sambungkan AI DM.
5. Buat dice/rules engine.
6. Buat dynamic visual scene generation.
7. Save/load campaign.

## Menjalankan
Buka `index.html` langsung di browser atau deploy folder ini ke GitHub Pages.
